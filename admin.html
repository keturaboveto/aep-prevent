Como adicionar, editar ou remover técnicos
Os usuários ficam no arquivo usuarios.js. Editar esse arquivo é simples e as mudanças valem para todos os dispositivos (celular, PC, tablet).
1
No GitHub, abra o repositório e clique no arquivo usuarios.js.
2
Clique no ícone de lápis (editar) no canto superior direito do arquivo.
3
Para adicionar um técnico, copie esta linha e cole junto às outras, mudando os dados:
{ usuario: "novonome", senha: "senha123", nome: "Nome Completo", tipo: "tecnico" },
4
Para trocar uma senha, mude o texto depois de senha:  Para remover, apague a linha inteira do técnico.
5
Role até o fim e clique no botão verde Commit changes. Em ~1 minuto as mudanças valem em todos os dispositivos.
Importante: como o repositório é público, as senhas ficam visíveis no código. Use senhas exclusivas deste app — nunca repita senhas de e-mail, banco ou outros serviços importantes.
